# Willbelony

I'm interested in software development, cloud infrastructure and interactive applications. This portfolio brings together infrastructure-focused engineering and an educational Roblox project in development.

## Featured projects

### [Flagship Cloud Project](https://github.com/Willbelony/flagship-cloud-project)

A task-tracker application focused on the infrastructure around it: Terraform-managed AWS networking and compute, a PostgreSQL database, container delivery, monitoring and GitHub Actions CI/CD using OIDC and Systems Manager.

**Stack:** Python, FastAPI, SQLAlchemy, PostgreSQL, Docker, Terraform, AWS (VPC, EC2, RDS, ALB, ECR, SSM, CloudWatch, IAM/OIDC) and GitHub Actions.

### [Mt. Zion: Little Lights](https://github.com/Willbelony/mtzion-little-lights)

A Bible adventure in development for children approximately ages 5–8. Implemented prototypes combine story exploration with building, gardening, food preparation and sharing, using per-player server state and local interactive presentation.

**Stack:** Roblox Studio, Luau, Rojo and Python verification tooling. I lead the concept, design decisions and Studio playtesting, with AI-assisted implementation and iteration. The game is not released or fully tested.
